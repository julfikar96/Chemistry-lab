# LEGENDARY CHEMISTRY ⚗️
### Interactive Chemistry Learning, 3D Simulation & AI-Powered Ecosystem

A modern, production-ready full-stack chemistry education and simulation platform built with React 18, TypeScript, Tailwind CSS, Three.js / Canvas 3D rendering, and Node.js Express with Google Gemini AI integration.

---

## ✨ Features

- ⚛️ **Periodic Table 2.0 (All 118 Elements)**: Complete atomic data, electron configurations, electronegativity trends, radius curves, ionization energies, and interactive element cards.
- 🧪 **Virtual 3D Laboratory Bench**: Realistic chemical mixing, heat adjustments, color shifts, precipitate formation, and gas evolution with real-time feedback.
- ⚗️ **Titration Curves Master**: Real-time titration simulation with pH meter, burette volume controls, equivalence point curves, and indicator color transitions.
- 🔋 **Electrochemistry & Galvanic Cells**: Dual-half-cell voltmeter simulator with salt bridge, electron flow, standard reduction potentials, and standard cell potentials ($E^\circ_{\text{cell}}$).
- 🧬 **VSEPR 3D Molecule Builder**: Interactive 3D molecular geometry explorer with ball-and-stick, space-filling, and wireframe views.
- 🌌 **Quantum Orbitals & Electron Configurations**: Visual Aufbau principle, Hund's rule orbital box diagrams, and quantum numbers $(n, l, m_l, m_s)$.
- ⚖️ **Algebraic Stoichiometry Balancer**: Instant balancing of complex chemical equations with molecular weights, molar mass breakdown, and mass percentage calculations.
- 🎈 **Gas Laws ($PV=nRT$) & Chemical Kinetics**: Ideal gas simulator with adjustable variables and reaction rate Arrhenius curves.
- 📖 **NCTB & SSC Practical Chemistry**: Guided virtual experiments with step-by-step procedures, observation logs, and quizzes.
- 🤖 **7-Mode AI Chemistry Tutor**: Powered by Google Gemini AI with modes for Exam Prep, Lab Safety, Homework Helper, Concept Deep Dives, and Step-by-Step Problem Solving.
- 📝 **Lab Notebook & Gamified Mastery**: XP system, daily streaks, unlocked badges, and persistent lab observations.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/legendary-chemistry.git
cd legendary-chemistry
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
Create a `.env` file in the root directory (based on `.env.example`):
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```

4. Run the development server:
```bash
npm run dev
```

The application will be accessible at `http://localhost:3000`.

### Production Build

```bash
npm run build
npm start
```
